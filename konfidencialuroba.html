კონფიდენციალურობის პოლიტიკა

ეს გვერდი აღწერს, რა მონაცემებს ამუშავებს „დადებითი“ (საიტი და მისი გვერდები სოციალურ ქსელებში). მოკლედ: ჩვენ მკითხველის პირად მონაცემებს არ ვაგროვებთ.

საიტი

საიტი შედგება ჩვეულებრივი გვერდებისგან. აქ არ არის რეგისტრაცია, კომენტარები, ფორმები, სარეკლამო ან სტატისტიკის კოდი, და ჩვენ ბრაუზერში მკითხველის ამოსაცნობ ფაილებს (cookies) არ ვწერთ.

საიტი განთავსებულია GitHub Pages-ზე. როგორც ნებისმიერი ვებ-სერვერი, GitHub ტექნიკური მიზნით შეიძლება ინახავდეს მოთხოვნის ჩანაწერებს (მაგალითად, IP-მისამართს); ეს მონაცემები ჩვენთან არ მოდის და მათ GitHub-ის წესები არეგულირებს.

სოციალური ქსელები

ჩვენი გვერდები Facebook-ზე, Instagram-ზე, TikTok-ზე, YouTube-სა და Telegram-ზე ამ პლატფორმების წესებით მუშაობს. პოსტების გამოსაქვეყნებლად ვიყენებთ პროგრამას, რომელსაც წვდომა აქვს მხოლოდ ჩვენს საკუთარ გვერდებზე: ის დებს ჩვენს პოსტებს და კითხულობს მათ საერთო სტატისტიკას (მოწონებების, კომენტარებისა და გაზიარებების რაოდენობას). ეს პროგრამა არ აგროვებს, არ ინახავს და არავის გადასცემს მომხმარებელთა პირად მონაცემებს.
